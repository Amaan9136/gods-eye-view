## Data sources used by the coastal layers kept in this build

- AISStream (vessel tracking) — https://aisstream.io
- NOAA GFS (wind) — https://www.nco.ncep.noaa.gov/pmb/products/gfs/
- NOAA NHC/CPHC (cyclone advisories) — https://www.nhc.noaa.gov
- USGS Earthquake Hazards Program — https://earthquake.usgs.gov
- Open-Meteo Marine API (wave height, sea surface temperature) — https://open-meteo.com — CC-BY 4.0 attribution appreciated
- INCOIS (tsunami advisory reference, not fetched by this app) — https://incois.gov.in
- PTWC (tsunami advisory reference, not fetched by this app) — https://ptwc.weather.gov

This project does not claim any INCOIS/PTWC data or endorsement — the in-app tsunami heuristic is our own client-side calculation and links out to these agencies for real confirmation.
